# 弱冷房車さがし

駅名を入れると、その駅を通る路線ごとに「10両は◯号車、8両は◯号車」と弱冷房車の位置を一覧で出すWebアプリです。

- ひらがなでも駅名を探せます
- 何号車かを小さな電車の図で光らせて表示します
- スマホのホーム画面に追加すると、アプリのように開けて、電波がなくても使えます

号車は時期や車両で変わることがあります。乗る前に車体の「弱冷房車」ステッカーも確認してください。
各路線の情報には「公式」（鉄道会社のサイトで確認）か「公式以外」（鉄道サイトなどから）の印をつけています。

## データ

- `data/stations.json` 駅と、その駅を通る路線
- `data/rules.json` 路線ごとの弱冷房車の号車（出典URLと確認日つき）
- `tools/` 上の2つを作るスクリプト

出典：駅・路線データは [station_database](https://github.com/Seo-4d696b75/station_database)（CC BY-SA 4.0）を加工しています。このリポジトリのデータも CC BY-SA 4.0 です。
